# Animal Rider (애니멀 라이더)

Animal-riding stunt runner built with TypeScript and Vite.

- Play (web build): https://rainforest-0305.github.io/animal-rider/
- This branch holds the **source**. The `main` branch holds the built web output served by GitHub Pages.

## Run

```bash
npm install
npm run dev      # local dev server (port 5183)
npm run build    # syncs zone assets, then builds into dist/
```

## Notes

- No ad SDK is included in this source.
- Build output (`dist/`), submission bundles (`*.ait`), and internal work logs are not tracked.
