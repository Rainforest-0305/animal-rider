# Animal Rider - PWA deploy folder

GENERATED by `store/build_pwa.py`. Do not hand-edit anything in this folder -
it is wiped and rebuilt on every run. Change the source or the script instead.

## The game

One-touch stunt riding. Hold to charge down a slope, release to launch, spin in
the air and land clean to keep the combo alive. 48 stages across 6 zones,
144 stars, 24 unlockable animals.

## Properties

- **Offline.** The shell is precached on first load and the zone artwork is
  warmed in the background right after, so the game runs with no network.
- **No ads.** No ad SDK, no interstitials, no rewarded video.
- **No sign-in.** No account, no email, no login of any kind.
- **No data collection.** No analytics, no tracking, no telemetry. Nothing
  leaves the device; progress and settings stay in local storage.
  See [privacy.html](privacy.html).

## Deploying

Publish this folder as the GitHub Pages root. `.nojekyll` is required: without
it Pages runs Jekyll, which strips any path beginning with an underscore -
that would silently 404 hashed asset paths and break the build.
